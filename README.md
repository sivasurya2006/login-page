# Login Page

A simple and responsive login page built with HTML and CSS. The project demonstrates a clean authentication UI with a centered login card, gradient background, form inputs, hover effects, and basic responsive layout behavior using Flexbox.

## Features

- Clean and modern login interface
- Responsive centered layout
- Username and password input fields
- Forgot password link
- Styled login button with hover effect
- Gradient page background
- Simple logo placeholder
- Built using only HTML and CSS

## Technologies Used

- HTML5
- CSS3
- Flexbox

## Project Structure

```text
login-page/
├── index.html

└── README.md
```

## Getting Started

To run this project locally:

1. Clone the repository.

```bash
git clone https://github.com/your-username/login-page.git
```

2. Open the project folder.

```bash
cd login-page
```

3. Open `index.html` in your browser.

No installation or extra setup is required.

## Usage

This project can be used as a beginner-friendly login page template or as a base for improving authentication UI designs. You can customize the colors, logo, fonts, and form behavior according to your project needs.

## Customization Ideas

- Add form validation using JavaScript
- Connect the form to a backend authentication system
- Replace the logo placeholder with a brand logo
- Add social login buttons
- Improve accessibility with required fields and ARIA labels
